# GestureCraft

原创 Rust 实现的 Windows 全局鼠标手势工具。

> 功能概念参考了 WGestures 2 的产品形态（手势列表、触发器、脚本动作等），但**全部代码为本项目原创**，未使用其任何代码、图标或资源文件。License: MIT。

## 功能（v0.1.0）

- 全局低级鼠标钩子，触发键可选 **右键 / 中键**；进入手势后自动吞掉事件，不会误弹菜单
- 轨迹按累计位移切段 → **方向序列（U/D/L/R）** 匹配，抗抖动
- 6 种动作：运行程序 / 命令行 / 打开网址 / 发送按键（`{ENTER}` `{TAB}` `{SLEEP 100}`）/ 窗口控制（最小化·最大化·关闭）/ **Rhai 脚本**
- 设置界面（egui，支持中文）：手势板直接拖动画轨迹、启停开关、阈值调节、实时日志
- 配置存于 `%APPDATA%\GestureCraft\config.json`，程序自身零安装

## 使用

1. 启动后默认监听右键：按住右键拖动超过阈值（默认 30px）开始录制手势，松开执行匹配动作
2. 内置示例：`DD` 最小化窗口、`DL` 关闭窗口、`LR` 打开资源管理器、`UD` 打开百度
3. 左侧栏可随时暂停/恢复监听

## 构建

本地（需要 Rust stable）：

```
cargo build --release
```

或直接推送到 GitHub，Actions 会自动构建 Windows x64 版本（`.github/workflows/build.yml`），打 `v*` 标签时自动附带 Release。

## 路线图

- 屏幕边缘 / 角落触发器、按目标应用分组
- 手势轨迹悬浮窗（WGPU 透明窗口）
- 托盘图标与开机自启
- Lua（WG2 式脚本 API 兼容层）

## 设计取舍

- 方向序列匹配（而非 $1 形状识别）：实现轻、可解释、便于手输序列
- Rhai 代替 Lua：纯 Rust 依赖，无 C 工具链负担；后续如需兼容 WG2 脚本再引入 mlua
- 暂不做点击抑制粒度控制（v0.1 全程吞事件），后续按目标窗口精细放行
